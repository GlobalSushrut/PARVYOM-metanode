## 🎯 USAGE GUIDELINES

### **Color Schemes:**

**Primary (Dark Background):**
```css
background: #0A1628 (Navy)
logo: Full color (Gold + White)
```

**Secondary (Light Background):**
```css
background: #F5F1E8 (Cream) or #FFFFFF (White)
logo: Navy monochrome
```

### **Sizing:**

| Usage | Minimum Width | Recommended Width |
|-------|---------------|-------------------|
| Website Header | 120px | 180px |
| Favicon | 32px | 64px |
| Social Media | 400px | 1200px |
| Print | 300 DPI | 600 DPI |

### **Clear Space:**

Maintain minimum 20px clear space around all logos.
