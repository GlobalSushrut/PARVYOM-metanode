## Step-by-Step Setup Instructions

### Step 1: Add Core Infrastructure Records

1. **Go to Cloudflare Dashboard** → DNS → Records
2. **Add A Record for Root Domain:**
   ```
   Type: A
   Name: @ (or pravyom.com)
   IPv4 address: <YOUR_DIGITAL_OCEAN_IP>
   Proxy status: Proxied (🟠)
   ```

3. **Add A Record for WWW:**
   ```
   Type: A
   Name: www
   IPv4 address: <YOUR_DIGITAL_OCEAN_IP>
   Proxy status: Proxied (🟠)
   ```

4. **Add CNAME Records:**
   ```
   Type: CNAME
   Name: api
   Target: pravyom.com
   Proxy status: Proxied (🟠)
   
   Type: CNAME
   Name: xtmp
   Target: pravyom.com
   Proxy status: Proxied (🟠)
   
   Type: CNAME
   Name: registry
   Target: pravyom.com
   Proxy status: Proxied (🟠)
   ```

### Step 2: Configure Email Records

1. **Add MX Record:**
   ```
   Type: MX
   Name: @ (or pravyom.com)
   Mail server: mail.pravyom.com
   Priority: 10
   Proxy status: DNS only (⚪)
   ```

2. **Add Mail Server A Record:**
   ```
   Type: A
   Name: mail
   IPv4 address: <YOUR_DIGITAL_OCEAN_IP>
   Proxy status: DNS only (⚪)
   ```

3. **Add SPF Record:**
   ```
   Type: TXT
   Name: @ (or pravyom.com)
   Content: v=spf1 ip4:<YOUR_DIGITAL_OCEAN_IP> include:_spf.google.com ~all
   ```

4. **Add DMARC Record:**
   ```
   Type: TXT
   Name: _dmarc
   Content: v=DMARC1; p=quarantine; rua=mailto:dmarc@pravyom.com
   ```

### Step 3: Configure SSL/TLS Settings

1. **Go to SSL/TLS → Overview**
2. **Set Encryption Mode:** Full (strict)
3. **Enable HSTS:** On
4. **Minimum TLS Version:** 1.2
5. **TLS 1.3:** On

### Step 4: Configure Page Rules

1. **Go to Rules → Page Rules**
2. **Add Rule for Static Assets:**
   ```
   URL: pravyom.com/*
   Settings:
   - SSL: Full (strict)
   - Cache Level: Standard
   - Browser Cache TTL: 4 hours
   ```

3. **Add Rule for HTTPCG Protocol:**
   ```
   URL: pravyom.com/httpcg/*
   Settings:
   - SSL: Full (strict)
   - Cache Level: Bypass
   - Disable Apps: On
   ```

### Step 5: Configure Security Settings

1. **Go to Security → Settings**
2. **Security Level:** Medium
3. **Challenge Passage:** 30 minutes
4. **Browser Integrity Check:** On
5. **Privacy Pass:** On

## Troubleshooting

### Common Issues

1. **"DNS resolution error"**
   - Wait 5-10 minutes for DNS propagation
   - Check if records are properly configured
   - Verify droplet IP is correct

2. **"SSL certificate error"**
   - Ensure SSL/TLS mode is "Full (strict)"
   - Check if origin server has valid SSL certificate
   - Wait for Cloudflare certificate provisioning

3. **"Email not working"**
   - Verify MX record is DNS only (not proxied)
   - Check SPF record syntax
   - Configure mail server on droplet

4. **"HTTPCG protocol not working"**
   - Ensure /httpcg/* page rule bypasses cache
   - Check if BPI VM server is running on port 7777
   - Verify proxy headers are configured
